三、總結性評量規準（A–D 四級）

規準一：程式設計（適用 Ch1–5、Ch8）

等第表現描述
A 優秀能獨立設計結構化程式解決新問題，會用邊界值測試並說明除錯過程
B 良好能正確運用選擇、重複結構與函式完成指定題目
C 基礎能參考範例修改程式完成題目
D 待加強僅能完成部分題目，或無法說明程式內容

規準二：資料結構與演算法（適用 Ch6–8）

等第表現描述
A 優秀能實作排序、搜尋與遞迴，並比較不同演算法的效率
B 良好能以串列與二維串列實作排序、搜尋
C 基礎能說明排序、搜尋演算法的步驟並追蹤執行過程
D 待加強僅能說明部分演算法步驟

規準三：資料處理與應用（適用 Ch9–10）

等第表現描述
A 優秀能以 API 取得即時資料、清理與分析，並說明資料限制與發現
B 良好能讀取開放資料並完成篩選、統計與圖表
C 基礎能依範例讀取資料並產生圖表
D 待加強僅能完成部分資料讀取
